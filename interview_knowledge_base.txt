Q: What is time complexity of binary search?
A: O(log n). Binary search halves the search space at each step. For n=1000 elements, it takes at most 10 comparisons (log2(1000) ≈ 10). This makes it much faster than linear search O(n).

Q: What is a deadlock? How can it be prevented?
A: Deadlock occurs when two or more threads are waiting for each other to release resources, causing all to be stuck. Prevention strategies: 1) Lock ordering - always acquire locks in same order. 2) Lock timeout - release lock if waiting too long. 3) Deadlock detection algorithms. 4) Avoid nested locks.

Q: Explain what overfitting is and how to prevent it.
A: Overfitting: model performs well on training data but poorly on new data. It memorizes noise instead of learning patterns. Prevention methods: 1) Cross-validation. 2) Regularization (L1/L2). 3) Reduce model complexity. 4) Get more training data. 5) Dropout (for neural networks). 6) Early stopping. Signs: low training error, high test error.

Q: What is the difference between mean, median, and mode?
A: Mean: average of all values (sum/count) - sensitive to outliers. Median: middle value when sorted - robust to outliers, use for skewed data. Mode: most frequent value - used for categorical data. Example: salaries [10k,12k,11k,100k] - Mean=33k (misleading), Median=11.5k (better represents typical salary).

Q: How would you handle missing values in a dataset?
A: Options: 1) Delete rows with missing values (if < 5% missing and random). 2) Mean/median imputation for numerical columns. 3) Mode imputation for categorical columns. 4) Forward/backward fill for time series. 5) Predict missing values using ML model. 6) Create a 'missing' category. Choice depends on: amount of missing data, whether missing is random or systematic, and impact on analysis.

Q: What is a p-value in hypothesis testing?
A: P-value is the probability of getting results as extreme as observed, assuming null hypothesis is true. If p-value < 0.05 (significance level), reject null hypothesis (result is statistically significant). If p-value > 0.05, fail to reject null hypothesis. Common mistake: p-value is NOT the probability that null hypothesis is true.

Role: Frontend Developer
Category: Technical
Difficulty: Hard
Q: Explain how the event loop works in JavaScript.
A: JavaScript is single-threaded. Event loop manages async operations: 1) Call Stack executes synchronous code. 2) When async operation (setTimeout, API call) is called, it goes to Web APIs. 3) When complete, callback goes to Callback Queue. 4) Event loop checks if call stack is empty, then moves callback from queue to stack. This is why async code runs after sync code.

Q: What is load balancing and why is it needed?
A: Load balancer distributes incoming requests across multiple servers. Needed because: 1) Single server can't handle millions of users. 2) Provides high availability - if one server fails, others handle traffic. 3) Improves response time. Role: AI/ML Engineer
Category: Technical
Difficulty: Medium
Q: What is RAG (Retrieval Augmented Generation)?
A: RAG combines retrieval and generation: 1) User asks a question. 2) System searches a knowledge base (vector database) for relevant documents. 3) Retrieved documents are sent to LLM along with the question. 4) LLM generates answer grounded in retrieved context. Benefits: reduces hallucination, allows LLM to access up-to-date/private data without retraining. Used in document Q&A, chatbots.

Role: AI/ML Engineer
Category: Technical
Difficulty: Medium
Q: What is the difference between fine-tuning and prompt engineering?
A: Prompt Engineering: crafting input prompts to guide LLM behavior without changing model weights. Fast, cheap, no training needed. Limitations: context window size, can't teach new knowledge. Fine-tuning: updating model weights on custom dataset. Teaches new knowledge/style, consistent behavior. Expensive, requires data and compute. Use prompt engineering first, fine-tune only if needed.

Q: What is a vector database and why is it used in AI?
A: Vector database stores data as high-dimensional vectors (embeddings). Used in AI because: 1) Text/images are converted to vectors by embedding models. 2) Semantic search - find similar meaning even without exact keyword match. 3) RAG pipelines - retrieve relevant context for LLMs. Popular options: FAISS (open source), Chroma, Pinecone, Weaviate. Core operation: cosine similarity search.

Role: AI/ML Engineer
Category: Technical
Difficulty: Hard
Q: What are hallucinations in LLMs and how to reduce them?
A: Hallucinations: LLM generates confident but factually incorrect information. Causes: training data patterns, lack of grounding. Reduction methods: 1) RAG - ground responses in retrieved documents. 2) Temperature = 0 for factual tasks. 3) Ask model to say 'I don't know' when uncertain. 4) Prompt with 'only answer based on provided context'. 5) Fact-checking pipeline. 6) Fine-tune on domain data.
